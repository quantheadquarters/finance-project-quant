Build from five example rules trade-level backtest on cached daily prices

Start with SMA crossover: it enters when a short moving average crosses a longer one. Change a length, then see whether it beats buying and holding over the same bars. A signal at one close fills on the next bar. Any reported lookahead violation voids the results.

To create your own rule, copy a built-in strategy into strategies/, edit generate_signals, then run ./start.sh strategy-backtest AAPL --strategy YourClass --chart aapl.html. The generated report uses TradingView Lightweight Charts for visual verification. Strategy files are loaded locally; the web API never accepts Python code.
