What Alpha Engine does

This open research framework gathers market data, computes reproducible evidence, and lets you test your own rules. The dashboard tracks what its example signal engine said; the workbench helps you form and check your own view. An optional language model can explain the numbers, but cannot choose them.

Or use it as infrastructure no browser required

The same tools the terminal calls are available over HTTP and over MCP. One tool table, three transports — they cannot drift apart. 

# the self-describing tool catalogue
curl localhost:8000/api/v1/tools

# call a tool
curl "localhost:8000/api/v1/tools/scan?asset=BTC"
curl -X POST localhost:8000/api/v1/tools/strategy_backtest \
     -H 'content-type: application/json' \
     -d '{"asset":"NIFTY","strategy":"SMACrossover"}'

# MCP over stdio, for Claude Desktop / Cursor / Windsurf
python -m alpha_engine.mcp
